# 离线测距定位（FastAPI + 原生 HTML/CSS/JavaScript）

完全离线运行的测距定位演示页面。用户录入坐标上界与若干信标的位置和欧氏距离读数区间，系统在 **0～N 的网格整数点** 上枚举所有可能位置，并在网格图上标出搜索区域。

## 一条命令启动（推荐，使用 Docker Compose）

```bash
docker compose up --build
```

启动后用浏览器访问：

> **http://localhost:8000**

停止：`docker compose down`。

## 不用 Docker 时本地启动

需要 Python 3.10+：

```bash
python -m venv .venv
source .venv/bin/activate          # Windows 为 .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

访问 **http://localhost:8000**。

## 定位规则

- 坐标上界 N 为 **2～40** 的整数，网格点坐标满足 `0 ≤ x,y ≤ N`（共 (N+1)² 个点）。
- 录入 **3～8** 个信标，每个信标包含：
  - 唯一 ID（非空、不可与其他信标重复）；
  - 整数坐标 (x, y)，必须在 `0～N` 内；
  - 非负整数距离闭区间 `[dmin, dmax]`，且 `dmin ≤ dmax`。
- 点到信标按**欧氏距离**计算，边界也算符合：
  `dmin² ≤ (x−xᵦ)² + (y−yᵦ)² ≤ dmax²`

求解过程：

1. 先枚举与**全部读数**一致的点。若存在，只展示这一组结果（按四邻接即上/下/左/右划分搜索区域）。
2. 若不存在，则**依次只排除一条读数**，分别求其余读数共同允许的点；每一种成立的排除都作为独立假设保留，**不同假设只做颜色叠加，绝不合并成同一片位置**；不成立的排除（无候选点）直接丢弃。
3. 若所有排除都不成立，显示「无法定位」。
4. 修改任意读数后立即作废旧结果并自动重算（防抖 300ms），重算期间图上会显示「旧结果已失效」遮罩。
5. 无效区间、越界坐标、重复 ID、信标数量不符等情况会逐条说明原因，并标红对应输入框。

## 复测布点建议

定位结果右侧（网格下方）提供「复测布点建议」面板，用于决定下一次测距站在哪里：

1. 输入**当前所在的整数格点** (originX, originY，须在 `0～N` 内) 与**最多可走的非负整数步数**（按曼哈顿距离 `|x−ox|+|y−oy|` 计，最大 200）。
2. 求解器把**每个成立假设的每个候选点**都视为一种可能情形（同一坐标被多个假设允许时按多种情形计）。假定复测能**精确给出到目标距离的平方（整数）**，则在某个候选布点处，读数相同的情形无法区分，构成一个读数分组。
3. 只考虑步数范围内、**未放置信标**的网格点。对每个候选布点计算各读数分组的情形数，取最大值（最坏剩余情形数）；推荐使该最大值**最小**的布点；最大组相同时选**步数最少**，再按 **y、x 升序**。
4. 面板显示推荐坐标、所需步数、最坏剩余情形数（为 1 时复测读数即可唯一锁定目标）、检查过的布点数，以及**每种可能读数 d²** 对应的假设（全部读数一致 / 排除哪条读数）与该读数下仍可能的候选点坐标；网格上用蓝色圆点标出推荐位置、虚线方框标出当前格点。
5. 特殊状态会说明原因：
   - **已唯一定位**：全部读数一致且只有 1 个候选点，无需复测；
   - **无法定位**：不存在任何成立的假设，没有可供复测区分的情形；
   - **没有可用布点**：步数范围内所有可达网格点都已放置信标（如步数为 0 且起点压在信标上），需增大步数或移动起点。
6. 修改任意读数、起点或步数都会**立即撤销旧建议**并自动重新计算；在途返回的旧响应不会重新显示。点击假设条聚焦某个假设只改变网格叠加显示，**不改变推荐结果**（推荐始终基于全部成立假设）。

## 页面与接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 定位页面（原生 HTML/CSS/JS，无任何外部 CDN 依赖） |
| POST | `/api/locate` | 提交 `{n, beacons:[{id,x,y,dmin,dmax}]}`，返回定位结果；输入非法返回 422 与逐字段错误 |
| POST | `/api/suggest` | 提交 `{n, beacons, originX, originY, maxSteps}`，返回复测布点建议；输入非法返回 422 与逐字段错误 |
| GET | `/api/health` | 健康检查 |

响应状态：

- `located`：全部读数一致，给出候选点与四邻接区域；
- `ambiguous_excluded`：全部读数无交点，给出所有成立的“排除一条读数”假设；
- `unlocatable`：所有假设都不成立，无法定位。

`/api/suggest` 的 `status` 取值：

- `recommended`：给出推荐布点 `recommendation`（坐标、步数、最坏剩余情形数、各读数分组的假设与候选点）；
- `already_unique`：候选点唯一，已唯一定位，无需复测；
- `unlocatable`：无任何成立假设，无法定位；
- `no_site`：起点步数范围内没有未放信标的网格点，无可用布点。
